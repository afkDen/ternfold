# Ternfold 0.2.0

This release includes the C17 compiler, reference interpreter, and native
runtime. It also includes the REPL, machine traces and replay, the formatter,
and a local editor service for diagnostics and hover.

Start with the source bundle if you want to build Ternfold or generate
native programs. The Windows x64 bundle can run the included examples
without installing a compiler. Run `ternfold.exe run counter.tfd` to try it.
Compare downloads with `SHA256SUMS.txt`.

The release checks cover Windows x64 with LLVM-MinGW Clang 23.1.4 (UCRT).
The classroom lexer has its own release series.

# Ternfold 0.2.1

This documentation update adds installation and checksum instructions, a CLI
reference, a runnable tutorial and troubleshooting guidance. The public
documentation now focuses on the language, compiler and supported workflows.

The repository also includes a labeled reconstruction of the C17 milestones.
CI replays five selected historical stage tests and checks the completed
compiler with strict warnings and ASan/UBSan.

Download the source ZIP to build Ternfold and native programs. The Windows x64
CLI ZIP can interpret the included examples without a C toolchain. Verify
both ZIPs against `SHA256SUMS.txt`.

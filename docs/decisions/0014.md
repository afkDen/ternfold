# ADR 0014: bounded offline formatter and editor adapter

Status: accepted. See [editor tooling](../editor-tooling.md).
Date: 2026-11-18. Owning task: optional M17 (after M14).

The production lexer retains ordered comment tokens and source spans. The
formatter validates with the production parser, then copies every non-EOF token
slice, including comments, verbatim. Whitespace gaps attach to the following
token and are replaced by deterministic spaces, LF and four-space brace
indentation. A touching minus/numeric-literal pair remains touching; a separated
pair remains separated because ADR 0010's minimum-Int rule observes adjacency.
No punctuation, parentheses, literal spellings or comment contents are rewritten.
Relexing and reparsing the candidate must succeed with an identical token stream
and identical minus/numeric adjacency before bytes are published. Empty input
formats to empty input. Formatting rejects source/lexical/syntax errors; it is
not a type-checking command. Output is owned and allocation failure is atomic.

The editor owns one immutable document snapshot per accepted version, together
with a fresh source manager and the existing virtual resolution, signatures,
type checker and machine analysis. Imports use the configured local root, with
the same virtual-root identity limitation as the REPL (no file overlay identity).
No execution occurs. Full-content revisions replace snapshots transactionally;
old snapshots can be retained by clients. Diagnostics and hover are published
only for the current version. UTF-16 coordinates exist only in this adapter and
reject surrogate-interior positions and CRLF-interior boundaries.
Versions are signed integers. Root plus imported source bytes have a 1 MiB
aggregate cap, and each snapshot has a 32 MiB live allocation budget. Failed
new revisions retain the prior snapshot. Imported diagnostics use their actual
file URI and UTF-16 ranges; prior dependency publications are cleared on change.

A synchronous, bounded stdio JSON-RPC adapter serves initialize/shutdown/exit,
one open URI, full-sync changes, close, diagnostics and type hover. Messages,
JSON depth/token counts, source bytes and response bytes have explicit limits.
No Node/Python/protocol library is needed. Cancellation of an already running
compiler call cannot be serviced by this synchronous loop; explicit library
cancellation and queued cancellation IDs suppress a later matching hover.
The service does not provide asynchronous cancellation of running compiler calls.
The queue holds 32 distinct cancellation IDs; overflow is an explicit host
failure. Multiple full-sync replacements apply in order, publishing only the
final version. Hover rendering clips depth/work with an ellipsis and continues
serving subsequent requests. JSON whitespace follows JSON rules, including CR.
Unknown requests return method-not-found; malformed framing fails the stream
without speculative resynchronization. JSON errors with intact framing receive
parse/invalid-request errors. No logs are written to protocol output.

The formatter and editor commands reuse the compiler's existing phases and
preserve language semantics. They are included in the shared build and test suite.

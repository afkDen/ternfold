# Changelog

## 0.2.1

- Expand installation, command reference, tutorial and troubleshooting guides.
- Document the reconstructed milestones and add focused stage replay to CI.
- Remove internal workflow notes from the public documentation.

## 0.2.0

- C17 frontend, reference interpreter, C emitter and native runtime.
- Immutable machine snapshots with dependency-ordered candidates, ordered
  guards and delayed emissions.
- Checked Int and Float arithmetic, records, enums, pattern matching,
  closures, local modules and source libraries.
- REPL, transition traces and replay, formatter, and a local editor service.
- Optional scalar folding and earlier release of eligible native values.
